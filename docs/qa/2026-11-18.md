## งานใหม่: เกาะที่สร้างเองขึ้น cloud (`?ibcloud`, รอ Paul)
ก่อนหน้านี้เกาะที่ผู้เล่นสร้างใน Island Builder อยู่แค่ในเครื่องเดียว ถ้าเปลี่ยนมือถือหรือกู้เซฟจาก Island Code เกาะจะกลับเป็นเกาะเปล่า
- เปิด lab แล้ว เกาะที่สร้างไว้จะถูกส่งไปพร้อม Island Code sync และ cloud save ของบัญชี ตอนกู้เซฟบนเครื่องใหม่ เกาะกลับมาด้วยและสร้างใหม่ทันที (ขึ้นข้อความ "Your built island came back too")
- เซฟเกมในเครื่องไม่ใหญ่ขึ้น (ใส่เกาะเฉพาะตอนส่งขึ้น cloud แล้วแยกออกตอนโหลด)
- ถ้า server ไม่รับเซฟที่ใหญ่ขึ้น (เกาะ ~78 KB) เกมส่งเฉพาะเซฟเกมเหมือนเดิม ไม่มีอะไรพัง
- ทดสอบด้วย `tools/qa-ibcloud.mjs` (server ปลอมใน container): ส่งขึ้น ✓ กู้คืนผ่าน Island Code ✓ เกาะสร้างใหม่จากเซฟที่กู้ ✓ server ไม่รับแล้วถอยกลับ ✓ cloud save บัญชี ส่ง/โหลด ✓ error 0
- **ยังไม่ได้ลองกับ server จริง** (container ต่อ Supabase ไม่ได้) Paul ลองบนมือถือได้:
  1. เปิด https://namchasang.github.io/quokka-cafe/?ibcloud
  2. ☰ → Play → Island Builder สร้างอะไรสักอย่าง แล้วกลับเข้าเกม
  3. ☰ → Island Code → sync (หรือ cloud save ของบัญชี)
  4. บนเครื่องอื่น (หรือหน้าต่าง private) เปิดลิงก์เดิม กู้เซฟด้วย code + recovery key: เกาะที่สร้างไว้ต้องกลับมา
- ถ้าโอเค: ตั้ง brief เป็น approved ใน Game Builder หรือพิมพ์ `ขึ้นเกมได้: ibcloud`
- ยังไม่ทำ: เพื่อนที่มาเยี่ยมเกาะ (Island Code visit) ยังเห็นเกาะเริ่มต้น ไม่ใช่เกาะที่เราสร้าง (ขั้นต่อไป)
