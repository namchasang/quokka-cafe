# Quokka Cafe and Friends

A cozy HD-2D café sim set on Rottnest Island (Wadjemup), Perth. Run a seaside café, grow a garden, befriend quokkas and locals, and travel by ferry and bus to South Perth, Heirisson Island, Fremantle and Victoria Park.

**Play:** https://namchasang.github.io/quokka-cafe/

- Plays in the browser on phone or desktop; add it to your Home Screen to install it as an app.
- Island Codes: get a code like `QK-4821`, back up your island to the cloud and visit friends' islands.
- Rottnest Island, South Perth and Heirisson Island are free. Fremantle and Victoria Park need the Perth Pass.
